# 📱 Gerenciador de Cartões

Aplicativo Android para gerenciamento de cartões, desenvolvido com foco em organização, usabilidade e boas práticas de desenvolvimento mobile e backend.

## 🎯 Objetivo

O projeto tem como objetivo permitir o cadastro, visualização, edição e gerenciamento de cartões por meio de uma interface moderna e intuitiva, integrada a uma API REST para persistência e processamento dos dados.

---

## 🏗️ Arquitetura

### Mobile
- Kotlin
- Jetpack Compose
- MVVM (Model-View-ViewModel)
- SQLite

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MongoDB
- SQLite
- API REST

---

## 🚀 Funcionalidades

- Cadastro de cartões
- Consulta de cartões cadastrados
- Atualização de informações
- Exclusão de cartões
- Persistência local dos dados
- Integração com API REST
- Interface moderna utilizando Jetpack Compose
